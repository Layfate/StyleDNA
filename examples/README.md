# Amber botanical study

The illustration and style profile are manually authored synthetic examples, licensed under the repository's MIT license. They demonstrate flat warm shapes, simple botanical forms, and subject-independent guidance. They are not AI-generated or a claimed result of semantic AI analysis.

Import `amber-study.zip` using the Skill Library's **Import package** action. To try measurement analysis yourself, import `amber-study.png` into a new studio draft instead. `SKILL.md`, `style.json`, and `references/` show the unpacked portable layout. Running `uv run python scripts/make-example.py` regenerates the example with fresh package identities.
