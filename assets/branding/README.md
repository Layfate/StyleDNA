# StyleDNA logo

`styledna-logo.png` is the logo supplied for this project, imported unchanged from **DNA Helix Photo Frame Icon.png**. The original has a transparent background; retain its colors, proportions, and transparency.

The sidebar uses this asset directly. Run `uv run python scripts/make-icons.py` to create the desktop PNG/ICO/ICNS sizes and browser favicon. These are format/size conversions of the supplied artwork, without new artwork or a replacement background.
