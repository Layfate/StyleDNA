# StyleDNA product scope

User clarification, 2026-11-15: **StyleDNA is an image-to-skill generator.** This clarification supersedes earlier plans that mentioned an integrated image generator or generated-image history.

The core workflow is:

**Upload reference images → analyze their style → review and edit the profile → generate `SKILL.md` → save, organize, and export reusable skills.**

StyleDNA produces instructions and portable skill packages. People can use those exports with their chosen AI tools. In-app image synthesis, generation-provider integrations, generated-image history, and model-training workflows are outside the product scope.

The application has four destinations: Dashboard, Image-to-Skill Studio, Skill Library, and Settings & Providers. Providers support reference-image analysis. Saved skill revision history remains part of the library.

Further work should improve style extraction, reference analysis, skill editing, package compatibility, privacy, reliability, accessibility, and desktop delivery. Missing image-generation features must not be described as incomplete StyleDNA work or placed on its roadmap.
